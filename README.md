# AI+ 信息素养检索助手\n\n基于 **Codex Skills + Playwright** 的信息素养学习与备赛工具。它接收完整题干和选项，优先复用适用证据与本地题库；需要补充资料时，再按证据缺口查询官方说明、API 或数据库页面。\n\n当前版本：**2.9.0**。支持单选题、多选题和判断题，答复包含答案、关键依据、来源和置信度。\n\n## 主要功能\n\n- **按证据缺口检索**：题内数据能够推导时直接计算，已有充分证据时停止重复查询。\n- **本地题库复用**：稳定题按题型、题干和选项文字匹配，并按当前选项映射答案；类似题只参考解析和方法。\n- **变化事实核验**：数量、排名、状态和产品功能等内容，按题目时间与口径补充证据。\n- **浏览器准备与会话复用**：输入“准备答题”后，启动或复用可见 Chrome，默认打开知网、万方、维普、读秀和超星汇雅，并保留登录页和验证码页。\n\n## 快速开始\n\n完整项目包需要 Windows、PowerShell、Node.js 20+、Google Chrome，以及支持 Skills 和持久 Node 工具的 Codex 环境。\n\n在包含 `setup.ps1` 的目录运行：\n\n```powershell\n.\setup.ps1 -Target both\n```\n\n然后在 Codex 对话中输入：\n\n```text\n使用 $ai-literacy-search，准备答题。\n```\n\n准备后发送完整题干和全部选项，或直接发送清晰截图。\n\n## 工作方式\n\n**理解题目 → 复用证据或题内推导 → 查询相关题库与规则 → 补充必要证据 → 核对全部选项 → 输出答案与来源。**\n\n资料目录包含 247 个网站或产品入口、306 条流程，这是目录覆盖量，不代表所有网站都能自动检索。\n\n## 使用边界\n\n- 页面打开不代表已经登录、拥有全文权限或检索成功；账号登录和验证码由用户在浏览器中完成。\n- 题库中的“标准答案”来自用户资料标注的样题或平台报告，不代表全部经过独立官网核验。\n- 置信度表示本题证据完整性的估计，不是统计正确率。\n- 本工具用于学习、备赛和信息核验，不自动开始考试、选择考试选项或交卷。\n\n完整项目包中的 `使用说明.md`、`ai-literacy-search/references/` 和 `runtime/` 提供详细配置、题库说明与浏览器接口。
